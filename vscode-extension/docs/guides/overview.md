			<main class="docs-main-content body"><h1>Extension Guides</h1>
<p>Once you have learned the basics of Visual Studio Code Extension API in the <a href="/api/get-started/your-first-extension">Hello World</a> sample, it's time to build some real-world extensions. While the <a href="/api/extension-capabilities/overview">Extension Capabilities</a> section offers high-level overviews of what an extension <strong>can</strong> do, this section contains a list of detailed code guides and samples that explains <strong>how</strong> to use a specific VS Code API.</p>
<p>In each guide or sample, you can expect to find:</p>
<ul><li>Thoroughly commented source code.</li>
<li>A gif or image showing the usage of the sample extension.</li>
<li>Instructions for running the sample extension.</li>
<li>Listing of VS Code API being used.</li>
<li>Listing of Contribution Points being used.</li>
<li>Real-world extensions resembling the sample.</li>
<li>Explanation of API concepts.</li>
</ul><h2 id="guides-samples" data-needslink="guides-samples">Guides &amp; Samples</h2>
<p>Here are the guides on the VS Code website, including their usage of the <a href="/api/references/vscode-api">VS Code API</a> and <a href="/api/references/contribution-points">Contribution Points</a>. Don't forget to refer to the <a href="/api/ux-guidelines/overview">UX Guidelines</a> to learn the user interface best practices for creating extensions.</p>
