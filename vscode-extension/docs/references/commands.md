			<main class="docs-main-content body"><h1>Built-in Commands</h1>
<p>This document lists a subset of Visual Studio Code commands that you might use with <code>vscode.commands.executeCommand</code> API.</p>
<p>Read the <a href="/api/extension-guides/command">Commands guide</a> for how to use the commands API.</p>
<p>The following is a sample of how to open a new folder in VS Code:</p>
<pre class="shiki" data-lang="javascript" shiki-themes dark-plus light-plus" style="--shiki-dark:#D4D4D4;--shiki-light:#000000;--shiki-dark-bg:#1E1E1E;--shiki-light-bg:#FFFFFF" tabindex="0"><code><span class="line"><span style="--shiki-dark:#569CD6;--shiki-light:#0000FF">let</span><span style="--shiki-dark:#9CDCFE;--shiki-light:#001080"> uri</span><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000"> = </span><span style="--shiki-dark:#9CDCFE;--shiki-light:#001080">Uri</span><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000">.</span><span style="--shiki-dark:#DCDCAA;--shiki-light:#795E26">file</span><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000">(</span><span style="--shiki-dark:#CE9178;--shiki-light:#A31515">'/some/path/to/folder'</span><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000">);</span></span>

<blockquote><p><strong>Note</strong>: You can review the full set of VS Code commands via the Keyboard Shortcuts editor <span class="filePreferencesPath"><strong>File</strong> &gt; <strong>Preferences</strong></span> &gt; <strong>Keyboard Shortcuts</strong>. The Keyboard Shortcuts editor lists all commands built into VS Code or contributed by extensions, along with their keybindings and visibility when clauses.</p>
</blockquote><h2 id="commands" data-needslink="commands">Commands</h2>
<p><code>vscode.executeDataToNotebook</code> - Invoke notebook serializer</p>
<ul><li><em>notebookType</em> - A notebook type</li>
<li><em>data</em> - Bytes to convert to data</li>
<li><em>(returns)</em> - Notebook Data</li>
</ul><p><code>vscode.executeNotebookToData</code> - Invoke notebook serializer</p>
<ul><li><em>notebookType</em> - A notebook type</li>
<li><em>NotebookData</em> - Notebook data to convert to bytes</li>
<li><em>(returns)</em> - Bytes</li>
</ul><p><code>notebook.selectKernel</code> - Trigger kernel picker for specified notebook editor widget</p>
<ul><li><em>options</em> - Select kernel options</li>
<li><em>(returns)</em> - no result</li>
</ul><p><code>interactive.open</code> - Open interactive window and return notebook editor and input URI</p>
<ul><li><em>showOptions</em> - Show Options</li>
<li><em>resource</em> - Interactive resource Uri</li>
<li><em>controllerId</em> - Notebook controller Id</li>
<li><em>title</em> - Interactive editor title</li>
<li><em>(returns)</em> - Notebook and input URI</li>
</ul><p><code>vscode.editorChat.start</code> - Invoke a new editor chat session</p>
<ul><li><em>Run arguments</em> -</li>
<li><em>(returns)</em> - no result</li>
</ul><p><code>vscode.executeDocumentHighlights</code> - Execute document highlight provider.</p>
<ul><li><em>uri</em> - Uri of a text document</li>
<li><em>position</em> - A position in a text document</li>
<li><em>(returns)</em> - A promise that resolves to an array of DocumentHighlight-instances.</li>
</ul><p><code>vscode.executeDocumentSymbolProvider</code> - Execute document symbol provider.</p>
<ul><li><em>uri</em> - Uri of a text document</li>
<li><em>(returns)</em> - A promise that resolves to an array of SymbolInformation and DocumentSymbol instances.</li>
</ul><p><code>vscode.executeFormatDocumentProvider</code> - Execute document format provider.</p>
<ul><li><em>uri</em> - Uri of a text document</li>
<li><em>options</em> - Formatting options</li>
<li><em>(returns)</em> - A promise that resolves to an array of TextEdits.</li>
</ul><p><code>vscode.executeFormatRangeProvider</code> - Execute range format provider.</p>
<ul><li><em>uri</em> - Uri of a text document</li>
<li><em>range</em> - A range in a text document</li>
<li><em>options</em> - Formatting options</li>
<li><em>(returns)</em> - A promise that resolves to an array of TextEdits.</li>
</ul><p><code>vscode.executeFormatOnTypeProvider</code> - Execute format on type provider.</p>
<ul><li><em>uri</em> - Uri of a text document</li>
<li><em>position</em> - A position in a text document</li>
<li><em>ch</em> - Trigger character</li>
<li><em>options</em> - Formatting options</li>
<li><em>(returns)</em> - A promise that resolves to an array of TextEdits.</li>
</ul><p><code>vscode.executeDefinitionProvider</code> - Execute all definition providers.</p>
<ul><li><em>uri</em> - Uri of a text document</li>
<li><em>position</em> - A position in a text document</li>
<li><em>(returns)</em> - A promise that resolves to an array of Location or LocationLink instances.</li>
</ul><p><code>vscode.executeTypeDefinitionProvider</code> - Execute all type definition providers.</p>
<ul><li><em>uri</em> - Uri of a text document</li>
<li><em>position</em> - A position in a text document</li>
<li><em>(returns)</em> - A promise that resolves to an array of Location or LocationLink instances.</li>
</ul><p><code>vscode.executeDeclarationProvider</code> - Execute all declaration providers.</p>
<ul><li><em>uri</em> - Uri of a text document</li>
<li><em>position</em> - A position in a text document</li>
<li><em>(returns)</em> - A promise that resolves to an array of Location or LocationLink instances.</li>
</ul><p><code>vscode.executeImplementationProvider</code> - Execute all implementation providers.</p>
