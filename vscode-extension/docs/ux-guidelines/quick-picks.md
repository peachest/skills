			<main class="docs-main-content body"><h1>Quick Picks</h1>
<p><a href="/api/extension-capabilities/common-capabilities#quick-pick">Quick Picks</a> are an easy way to perform actions and receive input from the user. This is helpful when selecting a configuration option, needing to filter content, or picking from a list of items.</p>
<p><img src="/assets/api/ux-guidelines/examples/quick-pick.png" alt="Quick Pick example" loading="lazy"></p>
<p><strong>✔️ Do</strong></p>
<ul><li>Use icons for clear metaphors</li>
<li>Use thoughtful icons that add clarity and help differentiate items</li>
<li>Use the description for displaying the current items (if applicable)</li>
<li>Use the detail for providing (brief) additional context</li>
<li>Use the multi-step pattern for a series of basic inputs</li>
<li>Provide an option to create a new item when picking from a list (if applicable)</li>
<li>Use a title for multi-step quick picks</li>
<li>Use a title for quick picks without a text input</li>
<li>Use a title for quick picks asking for text input (use the placeholder to show a hint or example)</li>
<li>Use a title for quick picks featuring global buttons (e.g. a refresh icon)</li>
</ul><p>❌ Don't</p>
<ul><li>Repeat existing functionality</li>
<li>Use a title when the placeholder can describe the purpose on its own</li>
<li>Use inputs without a placeholder</li>
</ul><h2 id="multiple-steps" data-needslink="multiple-steps">Multiple steps</h2>
<p>Quick Picks can be configured to feature multiple steps. Use these when you need to capture related-but-separate selections in a single flow. Avoid using quick picks for long flows with many steps—they aren't well suited to function as a wizard or similarly complex experience.</p>
<p><img src="/assets/api/ux-guidelines/examples/quick-pick-multi-step.png" alt="Multi-step Quick Pick example" loading="lazy"></p>
<p><em>Note the "1/3" text in the Quick Pick title that indicates the current and total number of steps in the flow.</em></p>
<h2 id="multiple-selections" data-needslink="multiple-selections">Multiple selections</h2>
<p>Use a multi-select quick pick for closely-related selections that need to be selected in one step.</p>
<p><img src="/assets/api/ux-guidelines/examples/quick-pick-multi-select.png" alt="Multi-step Quick Pick example" loading="lazy"></p>
<h2 id="title" data-needslink="title">Title</h2>
<p>Quick Picks can also be configured to show a title bar above the main input and selection UI. Use a title when the user needs more context for the selection being made. Avoid using a title that uses a label already used in the Quick Pick's input placeholder.</p>
<p><img src="/assets/api/ux-guidelines/examples/quick-pick-title.png" alt="Multi-step Quick Pick example" loading="lazy"></p>
<h2 id="using-separators" data-needslink="using-separators">Using separators</h2>
<p>Quick Pick items can be grouped into clear sections using Quick Pick separators. These feature a divider and label to clearly show the section. Use separators if the extension features a quick pick containing multiple obvious groups of selections.</p>
<p><img src="/assets/api/ux-guidelines/examples/quick-pick-separators.png" alt="Quick Pick with separators" loading="lazy"></p>
