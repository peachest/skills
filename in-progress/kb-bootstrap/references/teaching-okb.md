# Teaching OKB — bootstrap reference

Teaching knowledge (course material distilled into lessons) is owned end-to-end by the **`academy`** skill: it scaffolds courses as teach workspaces over a shared OKB (`bronze/silver/gold` per topic, RESOURCES.md consumption per course) and orchestrates multi-course cross-references.

## Bootstrap action

Run the `academy` skill's bootstrap for the academy (mission, curriculum, courses, shared OKB). Do not scaffold a teaching OKB by hand — academy's scaffold is the tested path, and a hand-rolled tree would drift from what its sessions expect.

Done when the academy bootstrap reports its course tree and shared OKB. This reference exists so the selection table routes teaching knowledge correctly, not to duplicate academy's contract.
