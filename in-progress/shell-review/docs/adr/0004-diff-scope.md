# ADR-0004: 扫描面默认 diff 感知，不做全仓扫描

日期: 2026-10-28
状态: accepted

## 背景

skill 定位是 ocr 的前置层（ADR-0002），评审面必须与 ocr 对齐（分支相对 base 的 diff）。hack/ 老脚本一次性清完后，全仓扫描没有日常价值。

## 决策

- 默认：审当前分支相对 base（origin/dev）改动的 `.sh` 文件。
- 显式传文件路径时按文件审。
- 不做全仓扫描模式。

## 后果

- diff 计算依赖 git 仓库上下文；在非 git 目录或无 base 分支时报错并指引显式传文件。
