# ADR-0002: 定位为 ocr 的前置机械闸，不替代 LLM 评审

日期: 2026-10-28
状态: accepted

## 背景

实测证明静态工具与 ocr（LLM 评审）互补：
- shellcheck 抓机械缺陷（SC2155 局部赋值掩盖返回值——LLM 八轮评审均漏掉）
- ocr 抓静态工具够不到的跨文件契约、注释失实、语义问题（新代码收敛轮 bot 全量评审曾抓出本地 ocr 0 findings 后仍有 5 个真 bug）

## 决策

skill 作为 ocr 的前置层：先跑静态三件套并逐条误报定谳，消噪后的残差连同 SC 码证据交给后续 LLM 评审。避免 LLM 浪费轮次在机械问题上。

## 后果

- skill 输出需可被 ocr 流程消费（评审面 diff 感知，与 ocr 对齐——见 ADR-0004）。
- skill 不承诺发现语义级问题，报告须声明覆盖边界。
