# zh 规则包（machine-auditable 子集 + 人工裁定项）

来源：触发标记与正则取自 lieflat-less-ai-tone 的语料实测规则（300 篇 AI 语料 × 5 模型对照人类写作，其 check-translationese.py 的 BASELINE 定义已内嵌进本 skill 的 audit.py，删除该 skill 不影响本表）；阈值与校准记录见各条目。**改写契约**：未命中规则的句子逐字保留；命中只是发出 flag，每处 flag 需裁定——承重保留（记录保留理由）或装饰修掉（最小改动，只动解决该问题必需的字）。

## 机器可检（audit.py ZH-*）

| id | 名称 | 触发标记 | 处方 | 裁定要点 |
|----|------|----------|------|----------|
| ZH-1 | 翻案腔 | 不是…而是／并非…而是／与其说…不如说／看似…实则／表面…实际／你以为…其实／说到底／答案恰恰相反 | 直接从正面下判断，先判断后依据 | 文章确实用材料走过"误解→修正"全程时允许自我修正，但禁用固定句式 |
| ZH-2 | 顿号罗列 | 一分句内 ≥2 顿号串 ≥3 项并列 | 能概括就概括；必须保留时改其中一项的句法 | 法规条目/配置清单类完整列举不改；Markdown 列表内部不改 |
| ZH-4 | 破折号 | `——` | 完整成句，或改逗号/句号 | **逐处裁定**：揭晓式改，承接式（"术语——释义"、解释性插入）保留并记入保留例；全文密度 >25/100 行（teach 校准：slop 30.3 / clean 23.6）触发整篇重审 |
| ZH-5 | 提示性冒号 | "一句话总结："“核心是："等提示语+冒号（lieflat BASELINE 词表） | 提示语不承信息→删；承上启下→换句号/逗号 | 句中总说加分说的冒号是规范用法，不改 |
| ZH-5b | 空转句引出列表 | ≤40 字、以：收尾、下一行是列表 | 该句写成有内容的判断，或删句留列表 | 列表项本身不动 |
| ZH-6 | 序数词当小标题 | 连续 ≥3 个 "一、二、…" / "第一，第二…" 编号小标题 | 删编号留文字 | 正文"首先…其次"（非小标题）不改；有序列表 `1.` 不改 |
| ZH-7 | 拟人喻体 | 像/如同/相当于 + 一个/一位 + 职业角色（导师/秘书/审查员…） | 换成它实际做什么，或具体的人当喻体 | 具体的人（"像老师傅"）人类就这么写，不改；比喻带来新信息时不改 |
| ZH-8 | 概括盖数据 | 显著提升/大幅增长/明显改善/大量的/众多 | 把同段已有的具体数值提到概括词位置 | 原文没有具体数据时只恢复动词，禁止编数字 |
| ZH-9 | 起手式 | 说白了／说穿了／先说结论 | 删掉，直接给判断 | — |
| ZH-10a | 翻译腔·当…时 | 句首"当…（的时偳|时），"完整主谓从句 | 删"当"和"时"，从句直接作前一分句 | 确需标示时点（删后时间关系模糊）不改 |
| ZH-10b | 翻译腔·话题壳 | 对于…来说／对…而言／就…而言／在…方面 | 对象直接放主语位，删壳 | 删后会被读成全局断言时保留 |
| ZH-10c | 翻译腔·句首连接词 | 段首"然而，/此外，/因此，/换言之，/总而言之，" | 移到主语后，或换"不过/其实/也" | 论证确实需要显式路标时保留 |
| ZH-10d | 翻译腔·这意味着 | 这意味着/这表明/这说明/换句话说 开头且与前句同义 | 并入前一句，或删提示语留结论 | 后句给出前句推不出的新结论时保留 |
| ZH-11 | 段首零主语 | 非首段以 听起来/看起来/值得注意的是/更重要的是/关键在于… 开头且无回指 | 补"这"字或点明对象 | 首段不改；已有回指不改；比喻独立成段只补回指不删比喻 |

## 仅人工裁定（不进机器审计）

- **ZH-3 相邻句结构同款**：相邻两句以上逗号数相同、成分顺序相同、长度接近 → 打散其中一句句法。机器近似检查误报率高，由改写者通读段内判定；清单式段落（操作步骤、并列条款）本来就整齐，不改。
- **负面清单（禁止作为改动理由，实测与人类写作无差别）**：句长/段长不够参差；单字虚词偏少；反复写全称；被动句；名词化与长句本身；句内同构排比（"提升效率，降低成本"）；正文问句/设问；比喻本身及独立成段；"首先…其次"正文序数。
- **信息守恒**：姓名/机构/数字/日期/引语/来源/因果一律不得新增或删除；限定词与让步（可能/通常/据说）不得抹掉、语气强度不得加重。机检入口： `python3 <SKILL_DIR>/scripts/conservation.py orig.md new.md`。
