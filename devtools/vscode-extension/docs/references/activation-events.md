			<main class="docs-main-content body"><h1>Activation Events</h1>
<p><strong>Activation Events</strong> is a set of JSON declarations that you make in the <code>activationEvents</code> field of <code>package.json</code> <a href="/api/references/extension-manifest">Extension Manifest</a>. Your extension becomes activated when the <strong>Activation Event</strong> happens. Here is a list of all available <strong>Activation Events</strong>:</p>
<ul><li><a href="/api/references/activation-events#onAuthenticationRequest"><code>onAuthenticationRequest</code></a></li>

<h2 id="onLanguage" data-needslink="onLanguage">onLanguage</h2>
<p>This activation event is emitted and interested extensions will be activated whenever a file that resolves to a certain language gets opened.</p>
<pre class="shiki" data-lang="json" shiki-themes dark-plus light-plus" style="--shiki-dark:#D4D4D4;--shiki-light:#000000;--shiki-dark-bg:#1E1E1E;--shiki-light-bg:#FFFFFF" tabindex="0"><code><span class="line"><span style="--shiki-dark:#CE9178;--shiki-light:#A31515">"activationEvents"</span><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000">: [</span></span>
<span class="line"><span style="--shiki-dark:#CE9178;--shiki-light:#A31515">    "onLanguage:python"</span></span>
<span class="line"><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000">]</span></span>
<span class="line"></span></code></pre>
<p>The <code>onLanguage</code> event takes a <a href="/docs/languages/identifiers">language identifier</a> value.</p>
<p>Multiple languages can be declared with separate <code>onLanguage</code> entries in the <code>activationEvents</code> array.</p>
<pre class="shiki" data-lang="json" shiki-themes dark-plus light-plus" style="--shiki-dark:#D4D4D4;--shiki-light:#000000;--shiki-dark-bg:#1E1E1E;--shiki-light-bg:#FFFFFF" tabindex="0"><code><span class="line"><span style="--shiki-dark:#CE9178;--shiki-light:#A31515">"activationEvents"</span><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000">: [</span></span>
<span class="line"><span style="--shiki-dark:#CE9178;--shiki-light:#A31515">    "onLanguage:json"</span><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000">,</span></span>
<span class="line"><span style="--shiki-dark:#CE9178;--shiki-light:#A31515">    "onLanguage:markdown"</span><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000">,</span></span>
<span class="line"><span style="--shiki-dark:#CE9178;--shiki-light:#A31515">    "onLanguage:typescript"</span></span>
<span class="line"><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000">]</span></span>
<span class="line"></span></code></pre>
<blockquote><p><strong>Note</strong>: Beginning with VS Code 1.74.0, languages contributed by your extension do not require a corresponding <code>onLanguage</code> activation event declaration for your extension to be activated.</p>
</blockquote><p>Additionally, if your extension needs to be activated before any language is used, you can use the generic <code>onLanguage</code> activation event to ensure this:</p>
<pre class="shiki" data-lang="json" shiki-themes dark-plus light-plus" style="--shiki-dark:#D4D4D4;--shiki-light:#000000;--shiki-dark-bg:#1E1E1E;--shiki-light-bg:#FFFFFF" tabindex="0"><code><span class="line"><span style="--shiki-dark:#CE9178;--shiki-light:#A31515">"activationEvents"</span><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000">: [</span></span>
<span class="line"><span style="--shiki-dark:#CE9178;--shiki-light:#A31515">    "onLanguage"</span></span>

<h2 id="Start-up" data-needslink="Start-up">Start up</h2>
<p>The <code>*</code> activation event is emitted and interested extensions will be activated whenever VS Code starts up.</p>
<blockquote><p><strong>Note:</strong> To ensure a great user experience, please use this activation event in your extension only when no other activation events combination works in your use-case.</p>
</blockquote><pre class="shiki" data-lang="json" shiki-themes dark-plus light-plus" style="--shiki-dark:#D4D4D4;--shiki-light:#000000;--shiki-dark-bg:#1E1E1E;--shiki-light-bg:#FFFFFF" tabindex="0"><code><span class="line"><span style="--shiki-dark:#CE9178;--shiki-light:#A31515">"activationEvents"</span><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000">: [</span></span>
<span class="line"><span style="--shiki-dark:#CE9178;--shiki-light:#A31515">    "*"</span></span>
<span class="line"><span style="--shiki-dark:#D4D4D4;--shiki-light:#000000">]</span></span>
<span class="line"></span></code></pre>
<blockquote><p><strong>Note:</strong> An extension can listen to multiple activation events, and that is preferable to listening to <code>"*"</code>.</p>
</blockquote><blockquote><p><strong>Note:</strong> An extension <strong>must</strong> export an <code>activate()</code> function from its main module and it will be invoked <strong>only once</strong> by VS Code when any of the specified activation events is emitted. Also, an extension <strong>should</strong> export a <code>deactivate()</code> function from its main module to perform cleanup tasks on VS Code shutdown. Extension <strong>must</strong> return a Promise from <code>deactivate()</code> if the cleanup process is asynchronous. An extension may return <code>undefined</code> from <code>deactivate()</code> if the cleanup runs synchronously.</p>
</blockquote>
