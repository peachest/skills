# 论文总结 Skill

## 使用场景

已有翻译后的中文 Markdown 论文（`<中文标题>.md`），需要生成结构化的章节摘要到 `brief.md`。

## 输入文件

- **必需**: 翻译后的中文 Markdown 文件（如 `论文标题.md`）
- **可选**: TeX 源文件（用于补充公式、图表定位）

## 执行流程

### 1. 识别章节结构

| 级别  | Markdown | 说明                           |
| ----- | -------- | ------------------------------ |
| `#`   | 一级标题 | 论文标题                       |
| `##`  | 二级标题 | 主要章节（摘要、引言、方法等） |
| `###` | 三级标题 | 子章节                         |

### 2. 五维度分析

对每个二级标题章节进行：

| 维度         | 说明                                     |
| ------------ | ---------------------------------------- |
| **核心问题** | 该章节试图解决什么问题？                 |
| **关键方法** | 使用了什么技术、算法、框架？有什么创新？ |
| **主要内容** | 核心论述（100-200 字）                   |
| **重要公式** | 记录位置和含义                           |
| **关键图表** | 记录图号和说明                           |

### 3. 生成 brief.md

```markdown
# 论文摘要：<中文标题>

## 基本信息

| 字段         | 内容                |
| ------------ | ------------------- |
| **中文标题** | [标题]              |
| **原文标题** | [Original Title]    |
| **更新时间** | YYYY-MM-DD HH:MM    |
| **来源**     | arXiv / 会议 / 期刊 |

---

## 核心贡献 (3-5 条)

1. [贡献 1]
2. [贡献 2]
3. [贡献 3]

---

## 章节摘要

### 摘要 (Abstract)
**核心问题**: ...  **关键方法**: ...  **主要内容**: ...

### 1. 引言 (Introduction)

**主要内容**: 研究动机、问题定义、主要贡献概述

---

### 2. 相关工作 (Related Work)
**核心问题**: 现有方法的局限性  **关键方法**: 分类对比
**主要内容**: 各类方法代表工作及局限、本文区别

---

### 3. 方法 (Method)
**核心问题**: 如何解决问题  **关键方法**: 技术列表
**主要内容**: [200-400 字]
**核心公式**: $$...$$  **关键图片**: Fig X

---

### 4. 实验 (Experiments)

#### 实验 1：[名称]
| 项目         | 内容                                                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------------------------- |
| **测试任务** | [任务描述]                                                                                                              |
| **测试目标** | [验证假设]                                                                                                              |
| **数据集**   | 名称、描述、规模、划分                                                                                                  |
| **评估指标** | Accuracy, F1, BLEU 等                                                                                                   |
| **实现细节** | batch size, lr, epochs, 硬件                                                                                            |
| **基线模型** | (大模型论文) 模型名、参数量                                                                                             |
| **基线方法** | 方法名、来源、核心思想                                                                                                  |
| **结果分析** | 论文重点结果和关键分析，重点记录从实验数据/现象到结论的逻辑链条（若原文阐述不充分，需结合实验上下文或整篇论文进行推导） |
| **结论**     | [1-2 句]                                                                                                                |

#### 实验 2：[名称]
...

### 5. 结论 (Conclusion)
**核心问题**: 总结和展望
**主要内容**: 贡献回顾、局限性、未来方向
```

### 4. 支持后续讨论

- **讨论**: 询问章节细节、解释方法、讨论实验
- **修改**: 补充内容、修正理解、调整重点
- **对比**: 与相关论文对比分析
- **实验**: 讨论实验设计合理性、基线公平性

## 输出要求

1. **简洁性**: 每章节 200-400 字
2. **结构化**: 统一格式
3. **可追溯**: 标注原文位置（§章节号）
4. **可讨论**: 留出讨论空间

## 领域适配

| 领域              | 重点                                  |
| ----------------- | ------------------------------------- |
| **软件工程/系统** | 架构设计、实现细节、评估方法          |
| **深度学习/AI**   | 模型架构、损失函数、训练策略、SOTA    |
| **计算机视觉**    | 网络结构、数据集、评估指标、可视化    |
| **LLM/NLP**       | 模型规模、训练数据、Prompt、Benchmark |
