## 六、注意事项

- 未声明但使用的 tools（如 grep, ls）是内置工具，不在 system prompt 中声明，不受移除影响
- 未声明但使用的 skills 是通过 `/skill:` 命令触发的，不占 prompt 空间
- 历史调用为零不等于永远不需要——功能性配套工具（如 goal_blocked）未来可能启用
- 本报告不修改任何配置文件——所有建议需用户手动执行
